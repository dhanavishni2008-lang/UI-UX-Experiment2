# UI-UX-Experiment2

## Aim:
To design a simple and attractive Music Streaming Mobile Application UI named "MeloVibe" using Figma, which allows users to explore songs, view trending music, and play their favourite songs easily.

## Algorithm:
1.Open Figma and create a new design file.

2.Select a mobile frame of size 390 × 844 px.

3.Design the splash screen with the app name "MeloVibe" and a headphone icon.

4.Create the home screen with a search bar and trending music section.

5.Add recently played songs with song names and images.

6.Design the music player screen with album artwork and song details.

7.Add play, pause, next and previous buttons.

8.Apply suitable colours, fonts, icons and backgrounds.

9.Connect the screens using Prototype mode.

10.Preview and test the application design.
